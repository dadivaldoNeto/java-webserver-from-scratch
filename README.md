# Java WebServer From Scratch

> Just for fun.

## 🇬🇧 English

Study project aimed at understanding the **Java** language by implementing an **HTTP web server from scratch**.

## 🇵🇹 Português

Projeto de estudo com o objetivo de entender a linguagem **Java** através da implementação de um **web server HTTP do zero**.
